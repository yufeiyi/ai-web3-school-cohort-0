## 学习内容

### 模块：提示词（Prompt）第二部分

**来源：** [Handbook Prompt 章节](https://aiweb3.school/zh/handbook/ai/prompt/)

#### Few-shot 精讲
- 好示例 + 坏示例比一堆好示例效果更好
- 示例不是一次性素材，要跟 eval 一起维护

#### Chain-of-Thought
- 让模型"一步步分析"，降低推理错误
- 适合：数学、多步分析、交易验证

#### System Prompt vs User Prompt
| 类型 | 谁控制 | 用途 |
|------|--------|------|
| System | 开发者 | 固定角色和规则，不应被覆盖 |
| User | 用户 | 每次任务的具体输入 |
| 检索内容 | 外部系统 | 标记为不可信数据 |

#### 结构化输出
```json
{
  "action": "explain_transaction",
  "risk_level": "medium",
  "asset_changes": ["-1 ETH"],
  "uncertainties": ["目标地址是否受信任"],
  "requires_human_approval": true
}
```
