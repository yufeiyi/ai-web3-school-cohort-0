## 学习内容

### Agent
- Tool Use：工具比回答更危险，输入schema和权限范围要明确
- Planning：计划只是候选路线，不是授权
- State：必须外置可查，不能只藏在 prompt 历史
- Reflection：自我检查可提高质量，不能替代确定性检查
- Multi-Agent：多个 Agent 放大协调问题

### Frameworks
- LangChain：组件库，适合快速接能力
- LangGraph：状态图，适合复杂多步工作流
- OpenAI Agents SDK：工具+handoff+guardrails
- DSPy：可优化的 prompt 程序
- 原则：先画清楚工作流，再选框架

### Evaluation
- 没有 eval 的 Agent 是不可管理的
- 必须能测试、回放、回归
