## 学习内容

### Chain-aware Context
- 链上状态（余额/交易/事件）必须实时进入 Agent
- 不是缓存旧数据，是实时查询

### Web3 Tool Use
- RPC 读 / 合约读（只读，安全）
- 签名 / 交易推送（写入，危险）
- 不同工具有不同权限等级

### Agent Workflow
- 只读步骤 → 自动执行
- 写入步骤 → policy 检查 → simulation → human check → 执行

### Agent Wallet
- Session Key：额度限制 + 时间限制 + 白名单 + 可撤销
- Policy：定义 Agent 能做什么不能做什么

### Machine Payment
- Superfluid / Sablier：流支付，按秒结算

### Settlement & Escrow
- 托管合约：锁定资产，条件释放
- 争议处理需要仲裁逻辑
