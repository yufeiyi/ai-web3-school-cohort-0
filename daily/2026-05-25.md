## 本周知识串联

### 核心认知链
```
LLM 是概率模型
  → 输出不是事实，需要外部校验
    → Prompt 是接口设计
      → 任务目标 + 输入边界 + 禁止行为 + 输出格式
        → 结构化输出让机器可检查
          → 但软约束 ≠ 安全边界
            → 代码层、权限层、人工确认层不可少
```

### 关键概念清单
| 概念 | 一句话 |
|------|--------|
| Token | 单位，决定成本和上下文长度 |
| Temperature | 控制输出确定性/随机性 |
| Hallucination | 编造，要外部校验来防范 |
| Instruction | 四段式：目标、输入、禁止、格式 |
| Few-shot | 示例引导，要跟 eval 一起维护 |
| CoT | 一步步推理，减少错误 |
| Structured Output | JSON/schema，后续代码可处理 |
| Prompt Injection | 不是靠 prompt 防，而是靠代码层防护 |
