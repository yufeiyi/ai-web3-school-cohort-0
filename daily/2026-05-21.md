## 学习内容

### 模块：LLM（大语言模型）

**来源：** [Handbook LLM](https://aiweb3.school/zh/handbook/ai/llm/)

#### 核心认知

> LLM 生成的是概率上合理的输出，而不是天然可信的事实。

LLM 本质上是一个**超高阶的自动补全引擎**——每一步只在问"下一个词最可能是什么"，走完所有步骤后，输出看起来像一个"答案"。它不是在找正确答案，而是在找一个个最顺眼的词。

**为什么会产生幻觉（Hallucination）？**
- LLM **没有"我不知道"这个选项**——它必须输出 token
- 当训练数据里没有信息时，它只能强行拼接出一个概率上合理的序列
- 这不是"它在编答案"，而是它**本来就没有在找答案**，它只是做自动补全，拼出来后发现"哦，看起来像个答案"
- 解决方案不是"让它别编"（架构决定的），而是：RAG 给真数据 + 结构化 JSON 校验 + 暴露不确定性

#### 关键概念

| 概念 | 理解 |
|------|------|
| **Token** | 模型处理文本的基本单位，中文每个字 1-2 token |
| **Temperature** | 0=确定性输出，1+=随机性。T=0 跑 3 次全一样；T=0.7 略有差异；T=1.5 可能跑偏 |
| **Hallucination** | 模型架构决定的必然行为——没有"不知道"选项，只能拼概率 |
| **Prompt** | 接口设计，不是魔法咒语。Instruction 四段式：目标/输入/禁止/格式 |
| **Structured Output** | JSON/schema，让输出可被代码检查和校验 |

#### Temperature 实验记录

| 模式 | 特点 | 区块链解释示例 |
|------|------|---------------|
| T=0（确定） | 干枯、教科书式、高信息密度 | "区块链是分布式的数字账本。数据以区块形式链接存储。不可篡改是核心特性。" |
| T=0.7（平衡） | 自然、日常对话 | "区块链是一个去中心化的账本系统。每个区块包含交易数据，用密码学链接。" |
| T=1.5（随机） | 有创意、比喻、可能跑偏 | "想象一个大家都可查看的公共账本，记录永不消失！" |

#### 对游戏项目的意义

- ✅ LLM 适合：NPC 对话、剧情生成、世界观描述、任务文案
- ❌ LLM 不适合：记住玩家资产、装备数量、任务进度——这些必须由数据库/链上状态管理
- ⚠️ 不能只靠 prompt 保安全：prompt 是软约束，真正的安全靠代码层校验和权限控制

## 今日思考：AI 时代什么最值钱？

今天学到最核心的结论，比任何技术细节都重要：

> **AI 时代 = 你的决断 × 你的判断质量 × AI 的执行速度**

### 三个能力变化

| 能力 | AI 能做吗 | 人类优势 |
|------|----------|---------|
| 记忆 | ✅ 完胜人类（读过整个互联网） | ❌ 不必再卷 |
| 谋划 | ✅ 能快速生成大量候选方案 | ❌ 优势缩小 |
| 决断 | ❌ 不能替人承担后果 | ✅ **人类最后的领地** |

### 决断力 = 在信息不完备、目标冲突、后果严重的情况下，做出选择并承担后果的能力

LLM 是概率模型，可以写 50 版方案，但永远不能替人做最终判断。产品策略、方向选择、风险承担——这些 AI 做不了。

### 重新定义"执行力"

- 以前的执行力：从 0 开始动手写
- 现在的执行力：**判断 AI 给的方案对不对 → 改 → 再判断 → 交付**

执行力的核心变成了"判断质量的执行密度"——你有多快判断 AI 的产出有没有坑、要不要换方向。

### 最终闭环：回到"决断"这个根

今天学完 LLM + Prompt，走完了一条完整的认知链路：

```
LLM 是概率模型
  → 它不知道自己在说什么，只是选下一个最顺眼的词
    → 所以它天然会编造（hallucination）
      → 所以它需要外部状态管理（数据库/链上）
        → 但 AI 自己判断不了"什么该存、什么不该存"
          → 这个判断（决断）只能由人来做
            → 所以 LLM 是推理层，人类是决策层
```

延伸到小说创作：AI 写长篇小说崩盘，核心原因和 LLM 幻觉一样——只关注"当前这一步怎么顺"，不关注"之前承诺过什么"。

延伸到 Web3+AI 游戏：链上能保证资产不可篡改，但 AI 自己判断不了"这个 NPC 的这句台词会不会影响未来 100 章的剧情"——这个判断力仍然是人的工作。

**结论：AI 时代，决断力 > 谋划力 > 记忆力。**

技能标签是"产品策略、研究写作、增长 BD"——这些本质上都是**决断密集型工作**。学 AI 不是为了取代自己，而是为了：AI 做谋划和生成，我做判断和决策。

> 今天 Day 1 学的"LLM 是概率模型不能当真相源"——这个判断力本身就是我现在最值钱的能力。大部分人看到流畅的输出就信了，我学了第一天就知道要问"它在编吗"。

## 打卡草稿

> Day 1（5/21）：LLM + Prompt。核心收获：LLM 不是一个"知道答案的智能体"，而是一个上阶自动补全引擎——每一步只选概率最大的下一个词，不是找正确答案。这就决定了它会编造没见过的东西（hallucination），也决定了它不能当真相源。做了 temperature 对比实验（T=0 确定 vs T=0.7 平衡 vs T=1.5 随机），理解了输出风格差异。学到的关键原则：Prompt 是接口设计不是咒语，是软约束不是安全边界。对游戏项目的启发：LLM 适合写剧情对话，不适合记玩家资产。
