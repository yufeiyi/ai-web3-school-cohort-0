## 学习内容

### Context
- Context Window：窗口大 ≠ 会用，长内容要配合检索和摘要
- Context Engineering：指令层 > 事实层 > 知识层 > 记忆层，逐层隔离
- Memory：跨请求保留信息，不能替代实时授权
- Knowledge Base：需要记录来源、更新时间、版本、适用网络

### RAG
- Chunking：按结构切（标题/API/FAQ），不是固定字数
- Vector DB：存向量 + metadata（来源/版本/可信度/时间）
- Retriever：不能只看语义，要过滤版本/环境
- Rerank：提高相关性和可信度
- Citation：答案要能追溯到原文
- 核心原则：RAG 的可靠性取决于证据链，不取决于向量库

### MCP
- Model Context Protocol：让工具、上下文、来源标准化接入
