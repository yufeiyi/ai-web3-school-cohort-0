## 学习内容

### 模块：LLM（第二部分）

**来源：** [Handbook LLM 章节](https://aiweb3.school/zh/handbook/ai/llm/)

#### Token 深入
- Tokenizer 切分：中文每个字 1-2 token，英文单词 1-3 token
- 长文档、代码、JSON 更容易塞满上下文
- "页面很短" ≠ "token 很少"
- 参考：[OpenAI Tokenizer](https://platform.openai.com/tokenizer) 直观测试

#### 关键参数
| 参数 | 作用 | 使用场景 |
|------|------|----------|
| Temperature=0 | 确定性输出 | 分类、数据提取 |
| Temperature=0.7 | 平衡 | 对话、常规生成 |
| Temperature=1.5 | 高度随机 | 创意写作（可能跑偏） |
| Top-P | 核采样，和 temperature 配合 | — |
| Max Tokens | 限制输出长度 | 防"废话连篇" |

#### 模型选型
- 推理/复杂任务 → Claude / GPT-4 / DeepSeek
- 简单分类/提取 → 小模型（GPT-4o-mini / Claude Haiku）
- 代码生成 → 选代码优化模型
- 亚洲语言 → DeepSeek / Qwen 系列
