## 学习路线

作为 AI 新手 + Web3 新手，按 Handbook 的四层地图逐步学习：

1. **AI 基础** → 建立模型、上下文、Agent 的共同语言
2. **Web3 基础** → 补上链上系统的直觉
3. **AI × Web3 Bridge** → 进入交叉问题
4. **前沿探索** → 组合成小原型
